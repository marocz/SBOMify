# SBOMify

SBOMify is an open-source tool designed to generate Software Bills of Materials (SBOMs) for improved security and compliance. It helps developers and security teams automatically create accurate inventories of software components, dependencies, and licenses to meet regulatory requirements and enhance vulnerability management. As a community-driven project, SBOMify aims to simplify SBOM generation while fostering transparency in the software supply chain.

## Planned Features
- Support for multiple SBOM formats (SPDX, CycloneDX, SWID)
- Integration with CI/CD pipelines for automated SBOM generation during builds
- Vulnerability scanning capabilities by correlating SBOM data with known vulnerability databases
- License compliance checking to identify permissive, copyleft, and restricted licenses
- Dependency tree visualization to understand complex software hierarchies
